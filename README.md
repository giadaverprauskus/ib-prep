# IB Interview Academy

A Khan Academy–style course for investment banking interviews. Multiple-choice practice with instant feedback and per-option explanations, end-of-lesson quizzes, and cumulative unit tests — laid out as one guided path from finance foundations through LBOs, plus behavioral prep. Single self-contained HTML file; progress is saved in the browser.

- ~390 multiple-choice questions across 15 technical lessons, generated from BIWS and Wall Street Prep interview guides
- Graded lesson quizzes and unit tests (80% to pass, full answer review)
- Behavioral lessons with reveal-style sample answers
- Full 1,200+ question bank searchable for reference

**Live site:** https://giadaverprauskus.github.io/ib-prep/
